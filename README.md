## 🧠 How I Build

I work at the intersection of **product thinking** and **AI-augmented execution**:

- **Architecture first** — I design the database schemas, API contracts, and system structure before writing large diffs
- **AI as my engineering partner** — I direct Cursor agents with precise strategy and context
- **Verify before ship** — Auth/RLS, payments, and the critical user path get a human pass
- **Ship fast, ship right** — Prefer a live URL, clean deploy, and a readable case study over localhost demos

Every feature has an owner. Every risky path is reviewed. Every release aims at something a customer can use.
